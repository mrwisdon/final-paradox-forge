# B8 H2 金块模块动画

> 初始记录：2026-08-02；动画代码修正：2026-08-02

## 问题

用户反馈原实现的金块投掷动画粗糙。只读诊断确认原实现虽然完成了生成、下落、
旋转、击碎、落地爆炸和开盾闭环，但遗漏了原版最重要的核心向外抛射阶段，并且
金块的尺寸和旋转轴不正确。

## 权威行为

- `h2/gen.mcfunction` 先在 `(-3828, 84.5, 1412)` 生成带黄色队伍发光描边的
  盔甲架头部金块，再把它传送到当前候选空中点并随机抬高 0/2/4/5/6 格。
- Minecraft 1.20.1 客户端把实体远距传送按 3 tick 做线性插值，因此玩家看到
  金块从矩阵核心高速撒向整片竞技场，而不是直接出现在最终位置。
- `h2/run.mcfunction` 每 tick 生成一个模块；所有模块每 tick 下落 `0.036` 格、
  yaw 增加 `3` 度，并在实体原点 +2 产生金色 dust 粒子。
- 原版使用完整尺寸盔甲架的头部物品变换：金块缩放为 `0.625`，中心约在实体
  原点 +1.6875；旋转中心是金块自身中心。

## 已实施修正

- 轻量模块实体继续保持服务器命中位置立即位于最终空中落点；renderer 单独
  复现从锚点 `(0, +6.5, 0)` 到最终落点的 3 tick 线性视觉插值，从而同时匹配
  原版视觉和命令判定语义。
- 金块改为 `0.625` 缩放、中心高度 `+1.6875`，并先居中后旋转，消除旧实现
  完整一格金块绕偏心轴画圈的问题。
- 旋转角度由绝对游戏时间和 partial tick 计算，保持 `3°/tick` 且帧间平滑。
- 模块恢复 `Glowing:1b` 及黄色描边，并保留原版金色 dust 粒子。
- 锚点与动画起始时间同步并持久化；中途加入或重新加载不会重新播放抛射。

## 仍需验证

- 必须在客户端从正面、侧面和俯视观察批量抛射、慢速下落、旋转轴和黄色描边。
  编译或构建成功不能替代视觉验证。
- 落地爆炸墨鱼墨环当前仍是 60 个环位，而原版 `boom.mcfunction` 是 64 个精确
  偏移；它不属于本次“投掷动作”修正。
